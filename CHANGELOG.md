# Changelog

## v0.2.0-experimental.3 — PatchGauge

- Unified the public repository, Python distribution and import, command,
  web interface, and VS Code integration under PatchGauge.
- Added checks that install the built wheel and exercise the installed command
  and packaged capability registry.
- Clarified that this prerelease offers tagged source archives only.
- Pinned a patched DOMPurify version for the web workspace.
- Preserved earlier experimental releases as immutable historical snapshots.

## Earlier experimental snapshots

The [previous prerelease](https://github.com/JulietBrown67/patchgauge/releases/tag/v0.2.0-experimental.2)
introduced a single-command check, direct source installation, engine fixes,
trend display, and an experimental conversation view. Its tagged files and
original evidence remain available for historical inspection.
