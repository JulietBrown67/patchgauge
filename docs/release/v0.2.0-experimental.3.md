# PatchGauge v0.2.0-experimental.3

This is an experimental, opt-in prerelease. The public repository, Python
distribution and import package, command, web interface, and VS Code
integration now use PatchGauge consistently. This version has no compatibility
alias for earlier import or command names. Existing local browser state is not
imported automatically; keep earlier reports and checkouts if needed.

## Install

This GitHub Release provides **source archives only**. No installer bundle is
attached, and this version has not been published to PyPI. With Python 3.11 or
newer, check out this exact tag, create a virtual environment, and run
`python -m pip install .`. Then use `patchgauge --help` or `patchgauge check`.
The [README](../../README.md) gives the complete commands.

## Included work

- Reversible test-evidence checks, a three-state report, history and trend
  display, and an experimental local conversation interface.
- A single public identity across package metadata, the installed command,
  application copy, extension settings, and documentation.
- Public CI checks on the release tag and main, including a clean wheel
  installation and CLI smoke check.
- A patched DOMPurify dependency for the web workspace.

## Limits

Evidence applies only to the declared repository, tests, and environment.
This release does not establish compatibility with arbitrary repositories,
semantic equivalence, or safety of deleting code. Independent hidden QA,
third-party compatibility trials, and user studies are not claimed. The
macOS sandbox remains a prototype; other platforms use trusted local mode.
The command does not push, merge, or publish code.

For security reports, use GitHub Private Vulnerability Reporting. Do not put
credentials, private paths, private source, or internal logs in public issues.
