# 水木验码 v0.2.0-experimental.2

这是公开实验版的第二个标签（experimental / opt-in），不是 stable、generally
available 或 production-ready 发布。相对
[v0.2.0-experimental.1](https://github.com/kuaikuaijisuanjishu-svg/modou-agent/releases/tag/v0.2.0-experimental.1)，
本版本把个人实用化阶段完成的单命令检查入口、可安装打包与一批引擎正确性修复带入公开树。

## 本版本新增（相对 experimental.1）

- **单命令只读检查（`shuimu check`）**：对当前工作区相对 HEAD 的增量做反事实移除
  实验，输出承重/无据/游离三态结论与逐行报告。终端一次确认，非交互环境失败关闭；
  可选只读预授权（绑定仓库、解释器、测试范围、预算与有效期，可随时撤销）。
- **仓库可直接安装**：根目录 `pyproject.toml` 提供 `shuimu` 命令，
  `python -m pip install .` 后即可使用（依赖见 `requirements-agent.in` 同源的
  `pyproject.toml` 声明）。
- **引擎正确性修复**：时间预算此前不约束探测阶段（用户设 120 秒实际按内部默认
  300 秒跑）——预算现在覆盖基线+探测整个会话；存在预算截断或未测量行时，报告的
  完成度字段如实标注 partial，不再与逐行缺口原因矛盾；macOS Seatbelt 沙箱实现
  随包分发，安装后可用。
- **历史与趋势**：每次检查归档报告与机器可读结果（含指回报告的路径）；
  `shuimu --trend` 展示历次检查的三态分布（分母与未标注同时展示）。
- **本地工作台新增对话入口（实验）**：与既有六步流程共用同一引擎与回执。

## 边界（与 experimental.1 相同，未因新能力放宽）

- 本版本的公开树来自经过脱敏检查的固定提交。发布证据只支持仓库内机器回归；
  不支持第三方仓库兼容性、任意仓库推广、语义等价、安全删除或自动 push、
  merge、publish。
- 独立隐藏 QA、独立 Linux 主机运行、授权私库灰度、真人开发者研究和 stable 所需
  的人工安全签字仍未完成；单命令检查与对话入口没有真人用户研究支撑，均属实验性
  opt-in 能力。
- 不宣称通过任何兼容性矩阵；`shuimu check` 当前只在 Python/pytest 路径上具备
  仓库内回归覆盖。沙箱为 macOS Seatbelt 原型：内存封顶与 fork 炸弹防护不可用，
  详见 `modou/sandbox.py` 的如实披露；非 macOS 平台回退受信任本地模式。
- 实验版不承诺固定修复时限。发现安全问题时，请使用仓库的 GitHub Private
  Vulnerability Reporting；非敏感问题可提交最小化公开 issue，不要附带凭据、私有
  路径、私有源码或内部日志。维护者可能先撤回 Release、关闭受影响能力，再发布
  修复版本。
